Known Limitations / 已知限制

Known Limitations / 已知限制
文档首页 快速开始 架构 生命周期 GitHub
中文English

这页记录 v0.3.1-beta 的实际边界，不是路线图承诺。

固定容量需要上层处理

App 启动、动画和 Popup API 可以报告容量或 transition 失败，但部分示例仍忽略返回值。AppManager::registerApp() 返回 void，注册数必须在启动前审核。各上限和调参方法见资源上限。

ListView 数据接口偏底层

ListItem 通过回调、union 和非拥有指针表示不同项目。它适合静态嵌入式数据，但类型安全和容量可观测性仍有改进空间。

非拥有数据的寿命由调用者保证

Widget 文本、XBM、Chart buffer、Popup 值引用、App 启动参数和 lambda 捕获通常不会被拷贝。统一规则见回调与对象生命周期。

并发边界很窄

tickFromISR() 是为定时 ISR 提供的特例边界。其他 API 的任务归属见事件驱动渲染。
