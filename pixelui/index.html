PixelUI 是我为小屏嵌入式项目编写的 C++ UI 框架，底层使用 U8g2 绘图，并用 ETL 提供固定容量容器和回调。它最初是为我自己的硬件项目写的，所以文档会尽量说清楚实际怎么用，也会保留当前实现的限制。

本 Wiki 以 v0.3.1-beta 为基线。

AppLauncher 在 Qt 模拟器中的运行效果。

从哪里开始 / Start here

  1. 快速移植：初始化 U8g2 和 PixelUI，接好时间、输入和刷新。
  2. 启动 AppLauncher：显示第一个页面。
  3. 构建第一个 App：了解生命周期、注册和退出。
  4. 使用 Widget 与 Focus：组件、父子树和按键导航。
  5. 使用动画 / 弹窗 / BlinkState。

常用界面 / Ready-made views

  • IconView 与 ListView
  • AppLauncher：基于 IconView 的应用入口。

  • PixelUI 架构概览
  • 事件驱动渲染与任务模型
  • App 生命周期与 ViewManager
  • 固定 App 内存区
  • 资源上限与 config.h
  • 回调与对象生命周期
  • 数值范围、格式化与编辑事务
  • Canvas 与页面滚动
  • Coroutine
  • 构建与测试模拟器
  • 已知限制
